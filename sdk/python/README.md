# Synapse Python Axon SDK

The `synapse-axon` package provides the `synapse_axon` Python client.

See the **[Python SDK guide](https://wbw1537.github.io/Synapse/python-sdk/)** for
installation, examples, configuration and lifecycle behavior. The guide is the
single maintained usage reference; its [source](../../website/docs/python-sdk.md)
is available before Pages is enabled.

SDK development and verification are recorded in
[internal testing](../../docs/testing.md#sdk-and-integrated-acceptance).
